# 📚 StudySpark

**StudySpark** is a fun and interactive web app to help students manage tasks, track progress, and stay organized.  

---
## ✨ Features
- Add, edit, and delete tasks with category, priority, date, and time.  
- Track task completion with a visual progress bar.  
- Calendar view for scheduled tasks.  
- Dark mode toggle for comfortable viewing.  
- Energetic UI with animations and celebratory popups.  

---
## 💻 Technologies
- HTML5, CSS3, JavaScript (ES6)  
- Responsive and animated interface  

---
## 🚀 Usage
1. Clone the repo:  
   ```bash
   git clone https://github.com/KondaKakarla/StudySpark.git
2.Open index.html in your browser.
3.Navigate: Welcome → Auth → Dashboard → Manage Tasks.
